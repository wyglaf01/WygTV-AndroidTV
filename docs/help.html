WygTV Help Guide

Everything you need to install WygTV, connect your TV service, and find your way around every screen and setting. WygTV is a player: it plays the channels, movies and series from the service or antenna you connect. It doesn't come with any of its own.

1. Install

Always-current download links are on the download section of the home page. You only install by hand once; after that, WygTV updates itself (see Manage app).

Amazon Fire TV (Stick, Cube, Fire TV smart TVs)

  1. On the Fire TV home screen choose Find → Search, type Downloader and install the orange Downloader app (by AFTVnews).
  2. Open Settings → My Fire TV → Developer options → Install unknown apps and switch Downloader to ON. If you don't see Developer options, go to Settings → My Fire TV → About and press OK on your device name seven times, then go back.
  3. Open Downloader, select the URL box and type:
    https://github.com/wyglaf01/WygTV-AndroidTV/releases/latest/download/wygtv.apk
    then press Go. (If you've been given a short Downloader code for WygTV, you can type that number instead.)
  4. When the download finishes, choose Install, then Done. Choose Delete when Downloader offers to remove the installer file.
  5. Open WygTV from Your Apps & Games. To pin it to the home row, highlight it, press the Menu button (☰) and choose Move to front.

Android TV, Google TV, NVIDIA Shield and other boxes

  1. Install Downloader from the Play Store (or use any file manager or browser that can open APK files).
  2. Allow it to install apps: Settings → Apps → Security & restrictions → Unknown sources (on Google TV: Settings → System → About, press Android TV OS build 7 times to unlock developer mode first, then Settings → Apps → Security & restrictions → Unknown sources).
  3. In Downloader, enter the same wygtv.apk link as above, then install.
Updating from a very old copy? Early test builds were signed differently. If Android says the app "can't be installed" or "conflicts with an existing package", uninstall the old WygTV once, then install again. Newer builds update over each other normally.

Windows and Ubuntu (WygDesktop)

Windows: download WygDesktop-Setup.exe (installs and adds a Start menu entry) or WygDesktop-Portable.exe (runs without installing). If Windows shows "Windows protected your PC", click More info → Run anyway.

Ubuntu 22.04 and newer: download the .deb and run sudo apt install ./WygDesktop-linux.deb, or download the AppImage, run chmod +x WygDesktop-linux.AppImage and open it.

WygDesktop has the same playlists, Live TV, TV Guide, Movies and Series. Keys: arrows move, Enter plays, hold Enter / right-click / M for options, Esc or Backspace goes back, S searches, F11 full screen. In the player, ↑↓ or PgUpPgDn change channel, number keys jump to a channel, Space pauses, I shows info.

Mac (WygTV-Mac)

WygTV-Mac is the same desktop app for macOS 11 Big Sur and newer. Check → About This Mac: if it says Chip: Apple M…, download WygTV-Mac-AppleSilicon.dmg; if it says Processor: Intel, download WygTV-Mac-Intel.dmg.

  1. Open the downloaded .dmg and drag WygTV-Mac onto the Applications folder.
  2. Open WygTV-Mac from Applications. Because it isn't signed by Apple yet, macOS says it can't check it for malicious software. Click Done (or OK).
  3. Open System Settings → Privacy & Security, scroll down to the message about WygTV-Mac and click Open Anyway, then confirm with your password. On macOS 14 and older you can instead right-click WygTV-Mac in Applications, choose Open, then Open again.
  4. If macOS ever says the app "is damaged", open Terminal and run xattr -cr /Applications/WygTV-Mac.app, then open it again.

The first time you add an HDHomeRun tuner, allow WygTV-Mac to find devices on your local network. ⌘Q quits, ⌘V pastes playlist addresses and F toggles full screen in the player. Settings → About & updates → Check for updates downloads newer builds; drag the new one into Applications to replace the old one. External player: install VLC in Applications and WygTV-Mac uses it.

2. First-time setup

The first time WygTV opens it shows Welcome to WygTV · Add your first playlist with four choices. Pick the one that matches what your provider gave you. You can add more later from Playlists.

⚙ Xtream Codes (server + username)

Use this if your provider gave you a server address, username and password. It gives you Live TV, Movies, Series and the provider's TV guide.

FieldWhat to enter
Playlist nameAnything you like, e.g. "Living room". Left empty, the server name is used.
Server URLThe address, like http://example.com:8080. You can also paste a whole get.php?username=…&password=… link and WygTV fills in the username and password for you.
Username / PasswordFrom your provider.
TV guide (XMLTV) linkOptional. Leave empty to use the provider's own guide.

Press Save & connect. WygTV checks the login first; if the provider says no or the account isn't active, nothing is saved and you'll see why.

☰ M3U link (playlist URL)

Use this for an .m3u or .m3u8 link. M3U playlists give you Live TV, grouped the way the playlist groups them. Enter a name, the link, and optionally a TV guide (XMLTV) link, then Save & load.

Tip: if the link you paste is really an Xtream Codes link (get.php), WygTV asks whether to add it as Xtream instead, which also gives you Movies, Series and the provider's guide.

📡 HDHomeRun (antenna TV tuner)

Watch free over-the-air channels from a SiliconDust HDHomeRun tuner on your home network.

  1. The address starts as hdhomerun.local, which most tuners answer to. Press Save & load channels.
  2. If it isn't found, press ⌕ Find tuners on my network and pick yours, or type the tuner's IP address (e.g. 192.168.1.50; you'll find it in your router or at my.hdhomerun.com).
  3. The channels appear in the side menu (📡), on Home and in the TV Guide as Antenna TV (or the name you gave the tuner). The guide comes free from the tuner.

If the tuner has no channels yet, run a channel scan in the HDHomeRun app first, then come back and choose Refresh channels (see Manage playlists).

↺ Restore from a backup

Moving to a new TV or reinstalling? Pick a WygTV-backup-….json file and everything comes back: playlists, favorites, channel groups, My List, hidden items and settings. See Manage app for how to make one.

4. Home & the side menu

Main screen. WygTV opens on option 1: rows of popular movies and popular series right now, from public lists that need no key or account (Rotten Tomatoes' popular movies at home and popular TV; if those don't answer, Apple's top movies chart and TVmaze's most popular shows airing now). The rows don't depend on your playlists. Scroll with ◀ ▶, move between rows with ▲ ▼; the top of the screen shows the highlighted title's year and scores. Press OK on a poster and WygTV looks for it in your playlists, then lists each playlist (and each copy, like HD or 4K) that has it: pick one to open its details page, the same as in Movies and Series. The list always offers Watch the trailer (on YouTube; no key needed), and Where else to watch it when a TMDb key is set. Above the rows is a row of shortcuts with everything the classic Home had: ▣ Live TV, ▦ TV Guide, ▶ Movies, ▤ Series, ⌕ Search, a 📡 tile for each antenna tuner, ☰ Playlists, ⚙ Settings and ⏻ Exit; Live TV is highlighted when the screen opens, and ▼ goes down to the posters. They're in the side menu too. To go back to the classic Home with tiles (option 2), choose Settings → Appearance → Main screen.

The classic Home (option 2) has four big tiles: ▣ Live TV, ▦ TV Guide, ▶ Movies and ▤ Series. Below them are shortcuts: ⌕ Search and a 📡 tile for each antenna tuner. Home also has buttons for ☰ Playlists and ⚙ Settings, and a small ⏻ Exit at the bottom right.

On other screens a slim side menu sits on the left edge. Press Back to open it (on a tablet, tap it). The arrow keys stay inside the screen you're on: at its edge the highlight simply stays put, so it never jumps into the side menu. It lists ⌂ Home, ▦ TV Guide, ▣ Live TV, ▶ Movies, ▤ Series (Movies and Series show whenever any switched-on playlist has them), a 📡 entry for each antenna tuner, ⌕ Search, ☰ Playlists and ⚙ Settings, with a small ⏻ Exit at the very bottom. Change the order in Settings → Appearance → Side menu order. Your ★ Favorites are the first entry inside Live TV.

On the main screen, Back moves the highlight into the side menu. Pressing Back again from the side menu (or choosing Exit) asks Quit WygTV? first, so you don't close the app by accident.

Recently watched lists the channels, movies and episodes you played, newest first, with how long ago. OK plays it again; hold OK to remove one; Clear the list empties it.

Live TV only mode (Settings → Appearance → App mode) hides Movies and Series. The app opens on the TV Guide and the side menu shows just TV Guide, Live TV, Search channels and Settings.

5. Live TV

The Live TV screen has a menu on the left third, and on the right a live preview above a 90-minute guide for whatever you highlight in the menu.

The menu (first level)

EntryWhat it shows
← MenuOpens the main menu on the left (or "← TV Guide" in Live TV only mode). Pick ⌂ Home there to go to Home.
★ FavoritesYour favorite channels. Highlighted when you open Live TV.
⌕ SearchType the channel name, then press ⌕ Search (or the search key on the keyboard). Nothing is searched while you type. Every saved playlist is searched, one at a time, and results appear as each one finishes. The first search downloads each playlist's channel list and saves it, so later searches are quicker; the lists are downloaded again after 6 hours or when playlists update.

Using it

  • Just highlight a menu entry and its channels fill the guide on the right after a moment.
  • Press OK or ▶ to move into the guide rows. The preview plays the highlighted channel.
  • Press ◀ or Back in the guide rows to return to the menu entry you came from. Back on a category under an open playlist closes the categories and puts you on the playlist. Movies and Series work the same way from the posters.
  • OK on a channel plays it full screen. Hold OK for: Play, Add/Remove Favorite, Program guide, Add to channel group…, Hide channel.
  • Inside a playlist's categories, ◐ Hide / show categories lets you tick which categories appear. Hold OK on a category for Hide this category or ▲ Collapse categories, which closes the list and puts you back on the playlist.
  • How many guide rows show under the preview (3, 4 or 5) is set in Appearance.

8. Movies & Series

Available for Xtream Codes playlists. Categories run down the left; the right is a poster wall, with an info panel above it showing the highlighted title's year, length, rating, genres and plot.

  • ⌕ Search at the top of the categories opens a search bar at the top of the screen, next to the MOVIES (or SERIES) title. It works like Live TV search: type the name, then press ⌕ Search (next to the bar) or the search key on the keyboard. Nothing is searched while you type. Every switched-on playlist is searched, one at a time, and posters appear as each one finishes; a result from another playlist names it under the poster. The first search saves each playlist's list, so later searches are quicker (lists are downloaded again after 6 hours or when playlists update). Your last results stay when you come back from a details page.
  • ☰ My List is your own watch-later list. Hold OK on a poster to add or remove it.
  • OK on a poster opens its details page: poster, plot, director, cast and ratings (IMDb, Rotten Tomatoes, Metacritic), with three buttons: ▶ Play (or ☰ Episodes for a series), ＋ My List and ▷ Trailer. Trailer opens the trailer in the YouTube app (or searches YouTube for it when none is listed).
  • Favorites are for Live TV channels. Movies and series go in My List instead; a ☰ before a title means it is in My List. Movie and series favorites from older versions were moved into My List.
  • Series remember where you stopped. Posters say "watched up to S2 E3", unfinished episodes resume where you left them, and an episode counts as watched past 90% or with under three minutes left.
  • On the episode list, pick a season, then an episode. Hold OK on an episode to mark it watched or not watched.
  • ◐ Hide / show categories works here too.

Ratings and extra details come from OMDb (built in) and, optionally, TMDb. See Appearance.

9. Favorites, channel groups and hiding

★ Favorites

Hold OK on any channel (or press OK while watching) and choose Add Favorite. Channels show their playlist logo; a channel without a logo shows just its name. In the TV Guide and the Live TV guide, hold OK on a channel to get the same choices plus Hide channel. The Favorites screen collects favorites from all your playlists, grouped by playlist. Playing one from another playlist switches to it automatically. Deleting a playlist keeps its favorites, so they return if you add it again.

◆ Channel groups

Your own categories that can mix channels from any playlist, like "Sports" or "Kids". Hold OK on a channel → Add to channel group… → pick a group or New category…. Groups appear in the Live TV menu and the TV Guide's ☰ Showing list. Rename or delete them by holding OK on the group, or in Settings → Manage playlists → Channel groups. Deleting a group never deletes the channels.

⊘ Hiding

Hide a category (◐ Hide / show categories, or hold OK on it → Hide this category). For an HDHomeRun antenna, open its TV guide (📡 in the side menu) and press ⊘ Hide / show channels at the top: a channel you untick there is hidden everywhere in the app. For other playlists, to hide or show channels, hold OK on a category in the Live TV menu → ⊘ Hide / show channels…: it lists only that category's channels, so ticks there only change that category. Hidden things disappear from lists, search, and channel up/down. To bring a channel back, open Search with nothing typed: hidden channels are listed there to unhide. To bring everything back at once: Settings → Manage playlists → Hidden categories and channels.

10. Playlists

Open ☰ Playlists from Home or the side menu (also Settings → Manage playlists → Manage playlists). Each row shows the name, type, server, and for Xtream the username and expiry date. Every playlist that is on (☑) is ready to watch at once in Live TV, Movies, Series, the TV guide, Favorites and Search, so there is no single playlist to pick. ☐ marks one that is off.

Press OK on a playlist for: Turn off / Turn on, Edit, Refresh now (re-downloads an M3U, or re-checks an Xtream account and its expiry, then downloads its TV guide again), and Delete. Each playlist shows when it was last updated, or ⚠ and the problem if its last update failed. ⟳ Update playlists and guides now updates everything at once. At the bottom: + Add an Xtream Codes login and + Add an M3U playlist link. HDHomeRun tuners are managed in Settings.

11. Settings

Settings works like a tree. It opens with the highlight on the SETTINGS column on the left (All settings, Manage playlists, Manage player, Subtitles, Appearance, Manage app), with the Manage playlists page beside it. Use ▲ ▼ and OK to open a group, or ▶ to go into the page's rows. Press ◀ to step back into the column and OK on another group to jump straight to it, or ▶ to go back to the page. Back from the rows returns to the column; Back from the column leaves Settings. All settings lists the five groups as big rows. Playlists opened from Settings keeps the same column, and Back returns to Manage playlists. Movies and Series work the same way: once you move into the posters, the category menu shrinks to a narrow column, and opens again when you go back into it.

12. Troubleshooting

ProblemTry this
"Login rejected or account inactive"Check the server address (including http:// and the port), username and password. Check with your provider that the account is active.
A channel stutters, freezes or won't startSettings → Manage player: switch Live stream format to HLS, raise the Buffer, or change the Video decoder.
Green blocks or a black picture with soundChange Video decoder (Software first ↔ Hardware first).
The guide is empty for some channelsAdd an Extra TV guide (a free one by country is easiest) or set your own TV guide source. Big guides can take a minute to load the first time.
HDHomeRun not foundMake sure the tuner is on and on the same network. Use Find tuners, or type its IP address; some devices can't look up hdhomerun.local.
"All tuners busy" / antenna channel won't playEach HDHomeRun has a few tuners; close other apps or TVs using it.
A category or channel disappearedIt may be hidden: Settings → Manage playlists → Hidden categories and channels.
Update won't installAllow WygTV to install unknown apps when asked. If you still have a very old test build, uninstall it once and install from the download link.
Movies and Series are missingThey come only with Xtream Codes playlists, and are hidden in Live TV only mode (Settings → Appearance → App mode).
